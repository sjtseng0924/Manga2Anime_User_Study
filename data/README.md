# Data Layout

Part 1 currently uses 8 storyboard groups. Part 2 keeps the same folder structure for later data. Put one image for each baseline in each group folder:

```text
data/
  part1/
    dualjustice1/
      ours.png
      animaker.png
      storydiffusion.png
      storyiter.png
      anystory.png
    dualjustice2/
      ours.png
      animaker.png

      storyiter.png
      anystory.png
    ...
    mado/

      anystory.png
  part2/
    dualjustice1/
      ours.png
      animaker.png
      storydiffusion.png
      storyiter.png
      anystory.png
    ...
    mado/
      ours.png
      animaker.png
      storydiffusion.png
      storyiter.png
      anystory.png
```

The web page expects these exact lowercase file names for Part 1:

- `ours.png`
- `animaker.png`
- `storydiffusion.png`
- `storyiter.png`
- `anystory.png`
